# DOMAIN_MODEL – KindEltern Admin / лист `Kartei`

Этот файл описывает структуру данных на листе `Kartei` в админском Excel-файле.
Описание сфокусировано на Excel-структуре листа и не фиксирует, в каких таблицах или
полях Access эти значения хранятся.

Актуализация сделана по старому stripped-снимку
`KindElternDaten_26_Admin_36.xlsx`. Она остаётся семантическим crosswalk для
листа `Kartei`, но факты о количестве sheets, used range, строках, формулах и
freeze panes не описывают текущий полный XLSM. Актуальный обезличенный профиль
полной книги: [admin-workbook-profile.md](admin-workbook-profile.md).

## 1. Общая структура листа

Лист `Kartei` является основной рабочей таблицей Admin/Operator. Структура данных
позиционная: бизнес-смысл задается номером колонки, а не заголовком в первой строке.

Факты ниже относятся только к stripped-снимку и не являются текущим source
contract. Рабочая позиционная модель находится в `A:BA` (колонки 1–53).
Used range, AutoFilter и formatting tail нельзя использовать как data bounds;
их точные operational coordinates не публикуются.

## 2. Типы строк

В stripped-снимке представлены обычные строки занятий/договоров, маркеры
`Zahlung`, `SEPA` и `PENDING`. Их operational counts не публикуются и не должны
использоваться как validation contract.

### 2.1 Обычная строка занятия/договора

Обычная строка описывает конкретную привязку ребенка к группе, предмету, преподавателю,
цене и помесячным начислениям.

Основные признаки:

- `D` содержит имя ребенка, а не `Zahlung`.
- `AV` содержит уникальный числовой `ID`.
- `A` содержит `FamilyID`, общий для строк одной семьи.
- `J:M` описывает текущую группу/цену.
- `O:S` используются для группы/цены следующего учебного года или перехода.
- `U:AF` содержат месячные суммы.

### 2.2 Маркерная строка `Zahlung`

Маркерная строка визуально отделяет семью/платежный блок.

Признаки:

- `D` после `Trim` равно `Zahlung`.
- `A` и `B` обычно повторяют `FamilyID` и родителя.
- `AV` также содержит технический `ID`; в текущем слепке такие строки являются частью листа.
- Часть служебных колонок (`AH:AJ`, `AU:AY`) может быть заполнена.
- Если в `C` стоит `SEPA`, макрос `SEPA` распространяет `SEPA` в `AU` на строки этой семьи.

Важно: маркерные строки не являются строками занятий, но их нельзя просто считать пустыми
или удаляемыми строками.

## 4. Месячный блок `U:AF`

Колонки `U:AF` соответствуют календарным месяцам января-декабря рабочего года из `O1`.
Значения обычно числовые и форматируются как `0.00`.

Эти колонки участвуют в:

- расчете начислений/стоимости по месяцам;
- блокировке изменений прошлых месяцев;
- проверке ограничений для `SEPA`;
- истории изменений с тегами `M01`-`M12`;
- массовых операциях перехода учебного года и индексации.

## 5. История изменений

История хранится в `AZ` как последовательность записей:

```text
[RUCK:]TAG(old->new);TAG(old->new)/@comment@/dd.mm.yyyy||
```

Основные разделители:

| Token | Значение |
| --- | --- |
| `||` | Разделитель записей истории. |
| `;` | Разделитель изменений внутри одной записи. |
| `->` | Старое значение -> новое значение. |
| `/@ ... @/` | Комментарий пользователя. |
| `RUCK:` | Ретроактивное изменение, обычно по уже прошедшему месяцу. |

Текущие history-теги из `Export_HistoryBuilder`:

| Tag | Колонка |
| --- | --- |
| `FID` | `A` |
| `PAR` | `B` |
| `CHD` | `D` |
| `DOB` | `E` |
| `ADR` | `F` |
| `TEL` | `G` |
| `MOB` | `H` |
| `EML` | `I` |
| `SB1` | `J` |
| `PR1` | `M` |
| `SB2` | `O` |
| `PR2` | `R` |
| `M01`-`M12` | `U:AF` |
| `EX1` | `AK` |
| `EX2` | `AL` |
| `EX3` | `AM` |
| `DCL` | Служебная запись отклонения Superadmin. |

Не все колонки листа имеют отдельные history-теги. Например, `K`, `L`, `N`, `P`, `Q`,
`S`, `T`, `AN:AT`, `AU:AY`, `BA` в текущем history-builder не представлены отдельными
именованными тегами.

## 6. Важные правила для обработки данных

- Колонка `AV` является надежным ключом строки; `A` не уникальна.
- Колонки `G` и `H` всегда обрабатывать как текст, иначе Excel может потерять ведущие нули
  или преобразовать номер в scientific notation.
- Даты в `C`, `E`, `AX` и время в `AY` могут быть представлены смешанно: Excel date/time
  или строкой. Код, который читает эти поля, должен быть tolerant к обоим вариантам.
- `D = "Zahlung"` означает маркер семьи, а не имя ребенка.
- `T = "KN"` используется как важный фильтр неактивных/прекращенных записей.
- `AU = "SEPA"` используется для ограничений Operator по изменению месячных колонок `U:AF`.
- `BA` является статусом workflow; сортировки и overlay-операции должны включать `BA`, чтобы
  статус не отрывался от строки.
- Строку 1661 не использовать как данные, несмотря на заполненные подписи колонок.
