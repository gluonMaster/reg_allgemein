# Образцы договоров

Все четыре локальных Word-файла реально используются Verein как операционные
образцы и служат business source для соответствующих цифровых шаблонов. Их
экономическую и операционную суть следует сохранять с учётом решений из
[CONTRACTS.md](../../docs/domain/CONTRACTS.md).

Сами DOC/DOCX не публикуются: они содержат контактные/банковские данные и
Office author metadata. Originals остаются read-only, игнорируются Git и не
используются как runtime-шаблоны. Каноническими для реализации являются
нормализованные спецификации и утверждённые versioned HTML/CSS template bundles,
а не содержимое локального файла само по себе.

| Нормализованный `template_id` | Операционный источник | Известные ограничения источника |
| --- | --- | --- |
| `group_yearly` | Годовой групповой договор, DOCX | Нет Word fields/content controls/bookmarks; упоминается отдельное приложение |
| `group_monthly` | Месячный групповой договор, DOCX | Нет template fields; встречаются дубли и незавершённые формулировки |
| `individual_hourly` | Договор индивидуальных занятий, legacy DOC | Нет template fields; lifecycle оплаты и срока требует нормализации |
| `nachhilfe_hourly` | Соглашение Nachhilfe, legacy DOC | Нет template fields; плательщик Jobcenter/Sozialamt моделируется отдельно |

## Правила использования

- Не изменять originals и не конвертировать DOC/DOCX в Worker runtime.
- Не копировать из них контакты, банковские реквизиты, подписи, Office metadata
  или другие реальные значения в код, fixtures, логи либо документацию.
- Извлечённое правило сначала фиксировать в каноническом domain/spec документе,
  согласовывать при наличии открытого вопроса и покрывать тестом.
- Цифровой шаблон вести как отдельную immutable version с change log и
  документированным approval уполномоченного представителя Verein.
- Минимальные корректировки и production blockers определены в
  [CONTRACTS.md](../../docs/domain/CONTRACTS.md); этот README не является
  юридическим заключением.
